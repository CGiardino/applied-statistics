# Applied Statistics

This repository contains my submission for the Applied Statistics module.
The project is written in a single Jupyter notebook, in Python.
Everything is self-contained, and the notebook can be run from start to finish without any additional setup.

## Quick Look

- You can click on [problems.ipynb](./problems.ipynb) to view the problems and their solutions.
- You can vew and run the notebook in [Google Colab](https://colab.research.google.com/)

## Running the Notebook

To run `problems.ipynb`, you can follow these steps:

1. Ensure you have [Python](https://www.python.org/) and [Jupyter](https://jupyter.org/) installed on your machine. You can install them using [Anaconda](https://www.anaconda.com/products/distribution/) or [uv](https://docs.astral.sh/uv/).

2. Clone the repository to your local machine using the following command:

   ```bash
   git clone https://github.com/yourusername/my-applied-statistics.git
   ```

3. Navigate to the cloned repository:

   ```bash
   cd my-applied-statistics
   ```

4. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Start the Jupyter server:

   ```bash
   jupyter notebook
   ```
